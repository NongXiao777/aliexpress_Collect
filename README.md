# 速卖通商品采集助手

独立的 Chrome Manifest V3 扩展，默认处理当前速卖通商品详情页。打开扩展即可核对标题、来源 ID、页面价格、图片和变体。可以下载 JSON，或复制去掉追踪参数的商品链接，交给智赢客户端的「产品 → 产品采集 → 单个采集」。

当前版本的入库动作使用智赢客户端的现有流程。提交后可在智赢采集列表核对编号。价格和库存来自读取时的页面，页面未提供的字段为空。

## 加载扩展

1. 在要使用的 Chrome 浏览器配置里打开 `chrome://extensions`。
2. 开启「开发者模式」，选择「加载已解压的扩展程序」，指定项目内的 `extension` 文件夹。
3. 打开一个速卖通商品详情页，点击工具栏上的「速卖通商品采集助手」。

扩展在点击后临时访问当前标签页，只读取商品字段。数据留在弹窗和用户选择的本地导出文件中。

## 验证页诊断（0.1.1）

遇到速卖通滑动验证时，扩展会显示「要求验证」或「验证失败」。页面提供公开错误码和失败次数时，弹窗也会显示它们。次数来自页面的反馈信息，可能为空。登录页会提示先登录。

如果人工验证仍失败，先暂停重试，保留当前窗口，等网站验证恢复后再点「重新读取」。读取只由打开弹窗或点击按钮触发。更新本地扩展后，在 `chrome://extensions` 点击该扩展的刷新按钮，再重新打开弹窗。

## 商品读取修复（0.1.2）

已加载的商品页会优先读取可见商品标题，并支持当前页面的价格布局。隐藏的站点标题不会再让商品被误判为未加载。更新后，在 `chrome://extensions` 刷新该扩展，再重新打开商品页上的扩展弹窗。

## 检查已打开的商品页

`scripts/browser-smoke.py` 需要 Python 3.9+ 和 Node.js 22+。使用已有 Chrome 的本机 CDP 地址，显式指定待测商品 ID。

~~~powershell
python scripts/browser-smoke.py --endpoint http://127.0.0.1:9222 --item-id 1005013209445272
~~~

把示例端口替换为现有浏览器的端口。脚本只连接给定的本机地址，读取已打开且 ID 匹配的商品标签页，检查采集结果和 JSON 序列化，然后断开连接。它保留浏览器及原有标签页。商品页重复打开时会返回待处理，先选定要保留的商品标签页再运行。

遇到验证码立即返回 `status: pending`。商品页缺失、未加载或需要登录时也返回待处理。成功返回 `status: passed`，包含标题、图片数、变体数及 `tabs_unchanged`；连接或校验失败返回 `status: failed`。退出码分别为 `2`、`0`、`1`。`tabs_unchanged: false` 表示检查期间有标签页或地址变化，需核对浏览器当前状态。

该命令检查项目内采集函数在真实商品页上的结果。扩展弹窗按钮、复制链接和下载动作由上述本地测试覆盖。Python 或 Node.js 未在 PATH 时，可使用 Python 可执行文件的完整路径，并通过 `--node` 指定 Node.js 路径。
